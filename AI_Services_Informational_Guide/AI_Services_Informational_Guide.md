## 2. OpenAI ChatGPT

### DESCRIPTION:
	OpenAI ChatGPT is a generative artificial intelligence chatbot that uses large language models to engage in human-like dialogue, answer questions, and create various forms of content.

### CORE CAPABILITIES
	* **Reasoning and Depth:** Features dedicated thinking and "Deep Research" modes that excel at long-form generation, logic puzzles, and complex problem-solving.
	* **Multimodal Actions:** Seamless integration of voice modes, advanced file uploads, and native image generation.

### AVAILABLE MODEL VERSIONS
	* **GPT-5.6 Sol:** The flagship frontier model designed for complex professional work, deep research, and advanced coding. Note: Sol Pro: Highest-tier reasoning access reserved for Pro and Enterprise users only.
	* **GPT-5.6 Terra:** A balanced everyday model optimized for standard workflows and middle-tier tasks.
	* **GPT-5.6 Luna:** An optimized, cost-efficient model built for speed and high-volume, lightweight processing.

### USAGE PROFILE
	* **Ideal for:** A "jack-of-all-trades" tool used for complex analytical problems, content strategy, and multi-step creative tasks.

### COST
	* **Free:** Access to foundational models (GPT-5.5 Instant) with limited daily limits.
	* **Go ($8/mo):** Expanded limits for casual, daily users.
	* **Plus ($20/mo):** Core plan featuring full reasoning models (GPT-5.6).
	* **Pro ($100–$200/mo):** High rate limits and early developer model access for power users.
	* **Business / Enterprise:** Starts at $20/seat/mo with custom compliance options for large organizations

### NATIVE ECOSYSTEM
	* Standalone / Web

### TARGET USER PROFILE
	* General Professionals, Researchers, Content Creators

## 3. Anthropic Claude

### DESCRIPTION:
	Anthropic Claude is an advanced artificial intelligence assistant and family of large language models created by the AI safety company Anthropic. It is designed to be helpful, honest, and harmless, excelling at complex reasoning, natural conversation, coding, and large-scale document analysis.

### CORE CAPABILITIES
	* **Text and Analysis:** Summarizes massive documents, answers detailed questions, and generates creative or professional writing.
	* **Coding:** Writes, debugs, and inspects software programs through specialized tools like Claude Code, which offers native terminal integration and sandboxed code execution environments.
	* **Large Context:** Processes huge amounts of input data at once, including reading hundreds of pages of text or entire code repository contexts simultaneously, allowing for deep analysis of hundreds of pages of text or complex codebases.

### AVAILABLE MODEL VERSIONS
	* **Opus:** The most powerful model built for deep reasoning and complex multi-step problems.
	* **Sonnet:** A balanced mid-tier model designed for high efficiency on regular work.
	* **Haiku:** A fast, lightweight model built for quick, simple daily tasks.

### USAGE PROFILE
	* **Ideal for:** Software developers, technical project managers, and legal or academic professionals processing heavy documentation.

### COST
	* **Free:** Basic web and mobile chats with file upload capabilities.
	* **Pro ($20/mo or $17/mo billed annually):** Includes Claude Code terminal access, project organization, and advanced models.
	* **Max ($100–$200/mo):** Up to 20x the message capacity of Pro for continuous engineering workflows.
	* **Team ($20–$125/seat/mo):** Shared workspaces, SSO protection, and centralized admin bills.

### NATIVE ECOSYSTEM
	* Standalone / Desktop

### TARGET USER PROFILE
	* Software Engineers, Technical Analysts, Developers

## 4. Google Gemini

### DESCRIPTION:
	Google Gemini is an artificial intelligence platform, a family of multimodal models, and a conversational chatbot.

### CORE CAPABILITIES
	* **Live Knowledge Grounding:** Uses Google Search to instantly weave verified, real-time facts into responses.
	* **Workspace Synchronization:** Directly pulls and modifies data inside Gmail, Docs, Drive, and Sheets.
	* **Multimodal processing:** Understands text, images, audio, and code natively.
	* **Google integration:** Works inside Gmail, Docs, Drive, and Maps.
	* **Deep Research:** Builds plans and scans the web or your files for detailed reports.
	* **Mobile assistant:** Acts as the default AI helper on Android phones

### AVAILABLE MODEL VERSIONS
	* **Gemini 3.6 Flash (gemini-3.6-flash):** Latest workhorse model balancing high-end coding/multimodal intelligence with superior token efficiency.
	* **Gemini 3.5 Flash-Lite (gemini-3.5-flash-lite):** Fastest and most cost-effective 3.5-class model built for high-throughput scaling.
	* **Gemini 3.1 Pro (gemini-3.1-pro-preview):** Preview flagship for advanced multi-step problem solving and agentic coding.
	* **Gemini 3.5 Flash (gemini-3.5-flash):** High-performance model offering near-Pro intelligence at Flash speeds.
	* **Gemini 2.5 Pro (gemini-2.5-pro):** Stable, mature high-capability model featuring a 1 million token context window.
	* **Gemini 2.5 Flash (gemini-2.5-flash):** Lightning-fast, versatile workhorse with controllable thinking budgets.

### USAGE PROFILE
	* **Ideal for:** Small-to-medium teams already running their businesses on Google tools, and research intensive workflows.

### COST
	* **Free:** Generous prompt windows powered by Gemini Flash models.
	* **Google AI Pro ($19.99/mo):** Adds Gemini 3.1 Pro, deep research tokens, and consumer bundles like YouTube Premium Lite.
	* **Google Workspace Bundles:** Automatically included for teams, no extra charge if subscribed to Google Workspace Business Standard ($14/user/mo).

### NATIVE ECOSYSTEM
	* Google Workspace

### TARGET USER PROFILE
	* Google Users, Researchers Tracking Live Data

## 5. Microsoft Copilot

### DESCRIPTION:
	Microsoft Copilot is an ecosystem-integrated orchestration layer rather than an independent standalone model. While platforms like ChatGPT, Claude, and Gemini are standalone destinations built by the companies that train the underlying artificial intelligence, Copilot acts as an enterprise shell that packages those advanced models directly into Microsoft 365 applications, Windows, and corporate data repositories.

### CORE CAPABILITIES
	* **App Native Automation:** Rewrites Word proposals, auto-generates PowerPoint slides, and breaks down Excel data sets natively.
	* **Graph Grounding:** Securely references internal corporate emails, chat logs, and SharePoint files.

### AVAILABLE MODEL VERSIONS
	Microsoft Copilot provides model versions from OpenAI and Anthropic across its ecosystem, featuring GPT-5 variants (such as GPT-5.5, GPT-5.3 chat, and GPT-5-mini), Claude models (like Claude Sonnet 5 and Claude Opus 4.8), and underlying GPT-4.1/4o architectures.

	**Microsoft 365 Copilot & Cowork Models**
	* **Auto (Default):** Automatically selects the best model for everyday tasks.
	* **GPT-5.5 (Frontier):** Versatile high-performance model hosted in Azure AI Foundry.
	* **Claude Sonnet 5 / Sonnet 4.8:** Optimized for rapid responses, efficient workflows, and drafting.
	* **Claude Opus 4.8:** Handles deep reasoning, complex research, and multi-step tasks.
	
	**GitHub Copilot Developer Models**
	* **Fast Lightweight:** Claude Haiku 4.5, Gemini 3 Flash, and Grok Code Fast 1 for small edits.
	* **General-Purpose:** GPT-4.1, GPT-5-mini, and Claude Sonnet 4.5 for standard coding functions.
	* **Deep Reasoning / Agentic:** GPT-5, GPT-5.2, and Claude Opus 4.5 for architecture and repo-wide workflows.

### USAGE PROFILE
	* **Ideal for:** Enterprise corporations and teams operating inside a strict Windows/Microsoft 365 ecosystem.

### COST
	* **Free (Copilot Chat):** Web-based companion tool for fundamental web searches.
	* **M365 Personal / Premium ($19.99/mo):** Unlocks Copilot functionality inside consumer Microsoft desktop applications.
	* **Copilot Business / Enterprise ($18–$30/user/mo add-on):** Requires an active underlying corporate Microsoft 365 licensing stack

### NATIVE ECOSYSTEM
	* Microsoft 365

### TARGET USER PROFILE
	* Enterprise Teams, Office Managers, Data Workers
